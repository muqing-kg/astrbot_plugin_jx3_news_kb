# JX3 News Knowledge Base Implementation Plan

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 实现 AstrBot 的剑网3公告知识库、混合检索问答、活动到期提醒和 WebUI 管理页。

**架构：** SQLite 保存公告、修订、分块、FTS5 索引、向量和活动提醒。AstrBot provider 提供问答、embedding 和 rerank 能力。Plugin Page 通过 `context.register_web_api` 调用插件后端，不另开端口。

**技术栈：** Python 3.12、aiohttp、SQLite/FTS5、AstrBot Star plugin API、原生 HTML/JavaScript/CSS Plugin Page。
